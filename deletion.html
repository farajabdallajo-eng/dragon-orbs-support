Dragon Orbs — Delete your game data / حذف بيانات اللعبة

Developer: FJ.Developer. Support: faraj.abdalla.jo@gmail.com.

Updated 20 November 2026. These instructions concern device-local game profiles; no remote game account database is operated.

Delete on your device

1. Open Dragon Orbs → Account.
2. Sign in with the Google account whose local game profile you want to remove.
3. Select Delete device profile.
4. Read the warning, then choose Confirm permanent deletion. Back to start cancels before confirmation.

This removes that profile's saved progress, saved round and local access history from this device and signs it out. It cannot be undone. It does not delete your Google account, Google Play orders or another profile, cancel a payment, request a refund, or remove data on another device. Repeat separately on each device. There is no developer-hosted game database or cloud progress backup. Empty ownership metadata and the shared installation key are retained to protect other profiles; they do not contain saved progress or the raw Google identity.

Request assistance without reinstalling

Email faraj.abdalla.jo@gmail.com with the subject Dragon Orbs — data deletion. Say whether you need help removing device-local game data or want support correspondence deleted. The developer cannot remotely erase a device-local save; you will receive instructions and an explanation of any applicable retention. Never send a password, identity token or payment-card details. A request does not require buying a pass.

If the app cannot open, Android Settings → Apps → Dragon Orbs → Storage → Clear data removes all local game profiles on that device, subject to Android behavior. This is broader than deleting one profile and permanently loses local progress and access records. Consider this scope before proceeding.

للمساعدة دون إعادة تثبيت اللعبة، أرسل إلى faraj.abdalla.jo@gmail.com بعنوان Dragon Orbs — طلب حذف بيانات، ووضح هل تحتاج إرشادًا لحذف بيانات الجهاز أم حذف مراسلات الدعم. لا يستطيع المطور مسح حفظ محلي عن بعد؛ سيقدم الإرشادات ويوضح أي احتفاظ مطلوب. لا ترسل كلمة مرور أو رمز هوية أو بيانات بطاقة. لا يتطلب الطلب شراء تصريح.
